# Waffle releases

Installers and the update manifest for **Waffle**, a step sequencer and song arranger.
The application itself is developed in a private repository; nothing but built bundles
and `latest.json` is published here.

This repo is public for one reason: a private repo's release assets need a token to
download, and an application cannot carry one without anyone who installs it being able
to read it back out of the binary. The bundles are signed instead, so this is a delivery
route rather than a trust boundary.

Written to only by CI. There is nothing here to clone.
